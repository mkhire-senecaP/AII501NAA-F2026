# Setup:

Be sure that deque and collection are installed on your version of python

# Testing:
Change the values of J1,J2, J3, and target for the jug gallon sizes and target gallon size.


# Execution and Assumptions:

The code runs through each jug's actions from when the jugs are filled, then poured into each other or emptied on the ground, to view the number of steps 
to reach the target gallon size through the shortest path.

The assumption is that the state space should be 6.
